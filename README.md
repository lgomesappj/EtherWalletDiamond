# EtherWalletDiamond

Ethereum-based, decentralized wallet utilizing multi-signature architecture for enhanced security and cold-storage integration via API gateway to blockchain platform.

With EtherWalletDiamond, you get a lightweight tool that stays out of your way.

**What you get**

- Ethereum-based, decentralized wallet utilizing multi-signature
- architecture for enhanced security and
- cold-storage integration via API gateway

## Key Features

- Ethereum-based, decentralized wallet utilizing multi-signature
- architecture for enhanced security and
- cold-storage integration via API gateway

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/EtherWalletDiamond.git`
2. `cd EtherWalletDiamond`
3. Install in editable mode: `pip install -e .`

## Configuration

EtherWalletDiamond is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
